# 配送先入力シートの仕様

Google Sheets 完結版（段階3）が読む `配送先入力` シートの仕様です。
CSVを作る側（受付書・Salesforce からの書き出し）と、貼り付ける側の共通の決めごとになります。

操作手順は [staff_manual.md](staff_manual.md)、管理者の初期設定は [admin_setup.md](admin_setup.md) を参照してください。
このドキュメントの例はすべて匿名の公共施設サンプルです。

## 1. テンプレートの作り方

メニュー `配送ルート > 配送先入力テンプレートを作成` を実行すると、次の形の `配送先入力` シートができます。

```text
     A         B       C                     D          E     F
1  配送日   （空欄）
2
3  id        name    address              priority    lat   lng
4  ← ここから下に配送先を貼り付ける
```

- B1 に配送日を入れます（例 `2026-08-15`）
- 3行目が見出し行です。4行目以降に配送先を貼り付けます
- `lat` / `lng` は空のままで構いません。実行時に自動で埋まります
- 既に `配送先入力` シートにデータがある場合、テンプレート作成は
  `「配送先入力」シートに既にデータがあるため、テンプレートを作りませんでした。` で止まります。
  中身を消すか、シート名を変えてから実行してください（既存データを上書きしません）

手で用意する場合も、この配置に合わせれば同じように動きます。

## 2. シートの構造

| 場所 | 内容 | 必須 |
| --- | --- | --- |
| 見出し行より上 | `配送日` ラベルと、その右のセルの日付 | `delivery_date` 列を使わないなら必須 |
| 見出し行 | 列名の行。`address`（または `住所`）を含む行が見出し行と判定される | 必須 |
| 見出し行より下 | 配送先の明細。`address` が空の行は無視される | 1行以上 |

見出し行は「`address` / `住所` を含む最初の行」で判定します。
そのため見出し行の位置は3行目でなくても動きますが、テンプレートに合わせるのが安全です。

## 3. 列の仕様

| 列名（英語） | 列名（日本語） | 型・書式 | 未入力のとき | 用途 |
| --- | --- | --- | --- | --- |
| `id` | `ID` | 文字列 | `D01` からの連番 | 出力の `ID` 列に入る識別子 |
| `name` | `配送先名` / `名前` | 文字列 | 住所がそのまま名前になる | 出力の `配送先名` 列 |
| `address` | `住所` | 文字列 | **その行は無視される** | 座標化とルート計算の入力 |
| `priority` | `優先度` | 整数（1が最優先） | `9`（最後尾） | 並び順の第1キー |
| `lat` | `緯度` | 数値 | 実行時に自動で埋まる | 入っていれば API を呼ばない |
| `lng` | `経度` | 数値 | 実行時に自動で埋まる | 同上 |
| `time_window_start` | `希望開始` | `HH:MM` | 空欄表示 | 出力の `希望時間` に表示（順序には未使用） |
| `time_window_end` | `希望終了` | `HH:MM` | 空欄表示 | 同上 |
| `service_minutes` | `作業分数` | 整数 | `0` | 出力の `作業分数` に表示（所要時間計算は未実装） |
| `delivery_date` | `配送日` | `YYYY-MM-DD` | `配送日` セルを使う | 出力タブ名になる日付 |

- 英語列名と日本語列名はどちらでも読めます。混在していても構いません
- 同じ役割の列が複数あるときは、左にある列が使われます
- 仕様にない列は無視されるので、備考列などを足しても問題ありません
- `priority` に数値以外が入っていると `9` として扱われます

## 4. 配送日

次のどちらかで指定します。両方ある場合は `配送日` セルが優先されます。

- 見出し行より上に `配送日` と書き、その **右隣のセル** に日付を入れる
- `delivery_date` 列に日付を入れる（最初に見つかった値を使う）

受け付ける形式:

| 入力 | 解釈 |
| --- | --- |
| `2026-08-15` | `2026-08-15` |
| `2026/8/5` | `2026-08-05` |
| 日付型のセル | スクリプトのタイムゾーンで `YYYY-MM-DD` に変換 |
| `8/15` | 認識されない（エラー） |

この日付がそのまま出力タブ名 `2026-08-15_配送ルート` になります。

## 5. 入力例（匿名サンプル）

```text
配送日   2026-08-15

id,name,address,priority,lat,lng
,,東京都江東区有明3-11-1,1,,
,公共施設C,東京都新宿区西新宿2-8-1,2,,
D004,,東京都千代田区丸の内2-4-1,3,,
```

日本語見出しでも同じ結果になります。

```text
配送日   2026-08-15

ID,配送先名,住所,優先度
,,東京都渋谷区神南1-19-8,1
,公共施設E,東京都港区海岸1-7-1,2
```

## 6. 件数と再実行

- 1回の実行で座標化するのは最大80件です（Apps Script の実行時間上限に合わせた制限）
- 80件を超えた回は、取得できた座標を `lat` / `lng` に書き戻すだけで、ルートタブは作りません。
  同じメニューをもう一度実行すると続きから処理され、全件そろった回にルートができます
- 座標は書き戻されるため、同じシートで再実行しても API 呼び出しは増えません。
  費用を抑えるため、`lat` / `lng` は消さないでください
- 座標を取れなかった住所はルートから外れ、実行後の通知に件数と住所が出ます

## 7. CSV を用意する側への注意

- ヘッダー行を必ず付ける（`address` または `住所` を含めること）
- 住所は1セルに収める（都道府県から番地までを分割しない）
- 全角スペースや改行を住所に入れない
- 建物名だけ・部屋番号だけの行は座標化できないため、番地まで入れる
- 実際の顧客名・担当者名を `name` に入れる場合、そのシートを公開範囲外で共有しない
  （このリポジトリのサンプルには実データを入れません）
