# 動作確認記録: Google Sheets 完結版（段階3）

実際の Google Sheets 上で `createRouteFromInputSheet`（メニュー `配送ルート > 配送ルート作成 (配送先入力シートから)`）を
実行し、期待どおりに動くことを確認した記録です。

- 実施者: 運用担当（az3azbe）が実スプレッドシートで実行
- 記録者: Devin（実行はしておらず、報告された結果の記録のみ）
- 対象: `apps-script/Code.gs` の段階3（PR #12 でマージ済み）
- 使用データ: 匿名の公共施設住所5件のみ（実顧客・実スタッフのデータは不使用）

このドキュメントには実スプレッドシートのURL、APIキー、スクリーンショットを含めません。

## 1. 前提条件

| 項目 | 内容 |
| --- | --- |
| スクリプト | `apps-script/Code.gs` をスプレッドシートの Apps Script に貼り付け済み |
| `GOOGLE_MAPS_API_KEY` | スクリプトプロパティに設定済み（値は非公開） |
| 起点設定 | スクリプトプロパティで会社センターを設定済み（住所は非公開） |
| Supabase | 段階3では使用しない（書き込みなし） |

設定手順は [admin_setup.md](admin_setup.md)、操作手順は [staff_manual.md](staff_manual.md) を参照。

## 2. 入力

`配送先入力` シートに、配送日と匿名サンプル5件を入力。

```text
配送日   2026-08-16

id,name,address,priority
（公共施設の住所5件。優先度付き）
```

住所はすべて公共施設の匿名サンプルで、`lat` / `lng` は空欄（座標化を実行時に行わせる状態）。

## 3. 実行手順

1. `配送先入力` シートに上記を入力
2. メニュー `配送ルート > 配送ルート作成 (配送先入力シートから)` を実行

## 4. 結果

| 確認項目 | 結果 |
| --- | --- |
| 出力タブの作成 | `2026-08-16_配送ルート` タブが新規作成された（配送日から命名） |
| 起点の表示 | メタ情報に会社センターが起点として表示された |
| 配送先件数 | 5 |
| 合計距離 | 30.39 km |
| 明細 | 配送順・ID・配送先名・住所・優先度・区間距離km・累計距離km が出力された |
| 座標の書き戻し | `配送先入力` シートの `lat` / `lng` に取得した座標が書き込まれた |

いずれも期待どおりで、ターミナルを使わず Google Sheets の操作だけで配送ルートを作成できることを確認しました。

## 5. この確認に含まれないこと

- 80件を超える入力での実行（ローカルのロジックテストでのみ確認: `node apps-script/tests/code_test.js`）
- 同じ配送日での再実行による `_2` 連番タブの作成（ロジックテストでのみ確認）
- 座標化に失敗する住所を含む場合の実 API 挙動
- 複数ユーザーによる同時実行
- Supabase への保存（段階3では行わない仕様）
- 実際の道路距離・所要時間との比較（距離は直線距離の目安）

## 6. 再確認したい場合

同じ内容を確かめるには、匿名の公共施設住所5件と配送日 `2026-08-16` を `配送先入力` シートに入れ、
同じメニューを実行してください。合計距離は使用する住所と起点によって変わります。
