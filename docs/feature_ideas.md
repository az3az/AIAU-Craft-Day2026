# 取り入れるとよい機能案

## 最初のデモで入れると強いもの

- 配送先の優先度
- 希望時間帯
- 作業時間
- 累計距離
- ルート結果のGoogle Sheets出力

## 次に入れると実務っぽくなるもの

- 車両ごとの積載量
- 担当ドライバー
- 出発地点・帰着地点の設定
- 配送不可時間の除外
- 当日キャンセル・追加配送への対応
- 配送完了チェック欄
- Google Mapsへのリンク

## Salesforce連携時に考えること

- Salesforce CSVの列名を固定する
- 顧客名、住所、電話番号、希望時間帯を取り込む
- 住所から緯度・経度を取得する方法を決める
- 個人情報を扱う列を最小限にする

## おすすめの進め方

ハッカソンでは、まずGoogle Sheetsだけで動く形にするのがおすすめです。
会社のGoogle Workspace内で完結しやすく、非エンジニアにも見せやすいからです。

本格運用では、住所から緯度・経度を取得する処理や、Google Maps APIを使った移動時間の計算を追加すると精度が上がります。
